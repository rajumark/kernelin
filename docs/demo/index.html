The code behind it

You write the Kotlin. At build time, Kernelin translates it into the WGSL (switch tabs to compare), which this page runs with WebGPU. The same Kotlin function also runs on the JVM in unit tests.

loading...

How it runs

Kotlin @Kernel function → K2 compiler → Kernelin plugin (IR → WGSL) → .wgsl + .json manifest → this page loads them with a ~150-line WebGPU host (kernelin-web.js) → your GPU.

The CPU side of the race is a JavaScript copy of the same loop running in the page, so both sides run in the same browser. Timings include copying the result back from the GPU, but not drawing it.
